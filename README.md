# Is This a Scam?

A free, mobile-first scam checker for India in Hindi, Bengali and English. Paste a suspicious
message, describe a call, or upload a "payment successful" screenshot, and get a verdict, the
red flags and the next step. It says "can't tell" instead of guessing.
